# 通用踩坑清单

按「口径 → 单位 → 结构 → 工具」四层归纳。每一条都是实际把成品做错过的类型，换公司仍会遇到。

## 一、口径层

| 坑 | 处理 |
|---|---|
| **年报 / 半年报混算 yoy** | yoy 只在同报告期间计算（年报对年报、半年报对半年报）。`endswith('年报')` 会匹配到「半年报」——必须先判半年报再判年报 |
| **跨年改名链断裂** | 产品线改名（旧名 → 新名）、行业合并/拆分，按各期原报告名称分别列示，不伪造可比关系；合并年度的数据不得塞进拆分年度的任一子项 |
| **「其他」被并入真实分类** | 行业板块排除「其他」；产品板块用残差法保留「其他」（产品合计 = 总收入）；地区板块内外销自洽 |
| **父类目与子项重复计数** | 「大类 + 其中：子项」结构下，父项已含子项金额，子项计入明细但不参与加总。加总 > 总收入是典型哨兵 |
| **上市前年份被跳过** | 招股说明书覆盖的年份必须补入；申报稿报告期通常比上市稿早一年，两版都要查 |
| **报告期错位** | 半年报附注「本期 / 上期」两列的年份归属要逐页确认，不能按上一年份惯性填 |
| **口径变化年份硬算可比** | 首次出现、统计范围变化、分类合并的年份，yoy 留空不写 0 |

## 二、单位与格式层

| 坑 | 处理 |
|---|---|
| **万元 / 元 未换算** | 统一为亿元（万元 ÷ 1e4，元 ÷ 1e8）；单位换算错误最容易靠「加总对不上」暴露 |
| **百分比存成百分数** | 单元格存小数（0.1234），配 `0.00%` 格式显示 12.34%；存 12.34 加百分比格式会显示 1234% |
| **占比用倒减法** | 占比 = 该项目营收 ÷ 营业收入合计 × 100%，分母用利润表口径；不用 `100% − 其他占比` |
| **空值填成占位符** | 成品表 Sheet 1 空值一律留空（`None`）；`--` 只用于中间表标记「已查证未披露」 |
| **新插入的列格式为 General** | 插列后必须逐行显式设置 `number_format`，格式不会从邻列继承 |
| **空值不留说明** | 留空必须在交付说明中给出原因，否则看起来像漏填 |

## 三、结构层

| 坑 | 处理 |
|---|---|
| **固定行号失效** | 增删行/列后旧行号全部作废：一律用 A 列标签动态定位，偏移只按「块首 + 固定 offset」 |
| **多块中间表按标签取行** | 「yoy / 毛利率 / 占比」等标签在多块结构中会命中第一个块 → 整块静默错位；用块首行号 + offset |
| **覆盖率不足的覆盖写入** | 新口径写入时跳过空值 → 旧数据残留；写块前先把目标块整块置 `None` |
| **列重构丢历史数据** | 删列/插列前先把已有数据读进内存，重构后按旧列 → 新列映射回填，再补新数据 |
| **合并/拆分行数变化** | 行的项目数逐年不同（行业数变化）时，固定行号映射会把数据填错行；逐年核对行标签 + 加总 |
| **销量口径混用** | 行业级销量不等于产品级销量，不进「主要产品销量」板块；金额口径的「销量」不是数量 |
| **明细金额超过合计** | 客户/供应商明细错位的哨兵：明细加总 ≠ 合计、明细 > 合计、出现负值 |

## 四、工具层

| 坑 | 处理 |
|---|---|
| **openpyxl 清空无效** | `ws.cell(r, c, None)` 是静默 no-op；必须 `ws.cell(r, c).value = None`，清完重读验证 |
| **删表头列破坏整表结构** | 删日期列表头会左移下方所有行（含备注表）；优先把表头 cell 置 `None`（软删除）而不是真删列 |
| **定点写 cell 覆盖用户手改版本** | 用户手工调过布局的成品表是 ground truth；此后只准许定点写单元格，禁止「复制模板重建」 |
| **脚本间互相覆盖** | 多轮修复必须合并成一个脚本一次 load → 改 → save；分脚本顺序执行时后脚覆盖前脚 |
| **核对循环静默跳过** | 期间命名不统一（半年报 / 中报）会让核对循环整段跳过而不报错；核对前后都要数覆盖条数 |
| **只看 tail 漏错误** | 校验输出必须看全量错误计数，不能只看末尾几行 |
| **数值断行解析** | PDF 文本层常见数字被拆行（`1,042,215.` + `37`）；解析前先合并断行，再核对同源数值 |
| **表头行污染标签** | 附注表头（「单位：元 / 本期发生额 / 上期发生额」）会与首个科目名粘成标签 → 标签收集时跳过表头行 |

## 五、流程层

- 接到任务先盘点**硬边界**：哪些年份/口径的数据有公开来源、哪些确实没有，先说清楚再承诺交付时间
- 数据源不可达时如实说明，不用估算值冒充实测值
- 空值、口径变化、来源为第三方数据库的年份，都在交付说明里单列
